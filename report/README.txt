IEEE CONFERENCE MANUSCRIPT

Compiled PDF: ../output/pdf/outliers_ieee_report.pdf (relative to report/ in the main checkout).
Editable source: main.tex; result table: results_clean.tex;
result-derived macros: numbers.tex; vector figures: assets/.

Compile main.tex from this directory using Tectonic or a LaTeX installation
with IEEEtran. The bibliography is included directly in main.tex.

The manuscript presents an empirical comparison of established regularization
methods. The numerical results and uncertainty definitions are unchanged.
Classroom framing, team branding, repository links and implementation-handoff
language have been removed from the manuscript. Author names and emails remain;
enrollment numbers are excluded.

No target venue, anonymous-review format, institutional affiliation or acceptance
status is assumed. Venue-specific submission rules require a separate check
once a conference is selected.
